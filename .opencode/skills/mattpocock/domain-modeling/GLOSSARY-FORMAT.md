# Suggested GLOSSARY.md format

Follow the repository's existing format first.

```md
# {Context name}

{Brief description of the context.}

## Language

**{Canonical term}**: {One- or two-sentence domain definition.}
_Avoid_: {Ambiguous synonyms, if useful}
```

Keep only domain-specific terms and concise definitions. For multiple contexts, follow `GLOSSARY-MAP.md` and keep glossaries within their respective contexts. The Coordinator must obtain explicit user approval before creating or editing one.
